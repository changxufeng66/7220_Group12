# 发给成员的消息（复制粘贴用）

你不用让每个人读完整份 README。把下面两段发出去就够了。

---

## 一、群公告版（短）

```
作业共享仓库搞好了：https://github.com/changxufeng66/7220_Group12

以后作业都放这里，谁都能接着别人的做。三个要点：

1. 收到邀请邮件（或去 https://github.com/notifications ）点「接受」
2. 第一次用：git clone https://github.com/changxufeng66/7220_Group12.git，登录弹窗选「Sign in with your browser」
3. 改之前先 git pull；改的时候开自己的分支，别动 main；
   动手前先在对应作业的「接力记录.md」里加一行，写清你接哪块

详细步骤看仓库里的 README.md，卡住了看 docs/常见问题.md。
```

---

## 二、私聊版（第一次用 git 的人）

```
仓库：https://github.com/changxufeng66/7220_Group12

第一次只有三步，大约 5 分钟：

① 接受邀请
   邮箱里找 GitHub 的邀请邮件，点 Accept invitation。
   没收到就打开 https://github.com/notifications 点接受。

② 装好 git 并配置身份（装过 git 的话只跑这两行）
   git config --global user.name  "你的名字"
   git config --global user.email "你的GitHub邮箱"
   ※ 邮箱要和 GitHub 账号的一致，不然提交不算你的

③ 下载仓库
   cd 到你放作业的目录
   git clone https://github.com/changxufeng66/7220_Group12.git
   cd 7220_Group12
   第一次会弹登录窗口，选 "Sign in with your browser" 登录一次就好。

之后每次干活就四步：
   git switch main && git pull
   git switch -c feat/w03-lab02-你的名字
   （改文件，并在「接力记录.md」里加一行说明你接了什么）
   git add -A && git commit -m "feat(w03-lab02): 完成第3题" && git push -u origin 你的分支名

然后去网页点 Compare & pull request，填模板，等人合并。

⚠️ 两个坑：
· 不要直接在 main 上改
· docx/pptx 不能两个人同时改同一份（git 合不了），改之前先在接力记录里声明

完全不会的话，先照着 README 第三节走一遍，报错直接贴出来。
```

---

## 三、如果有人问「我该做什么」

回答他：

1. 打开相应作业文件夹的 `接力记录.md`，看**最后一行**
2. 最后一行写着 `待接手` + 卡点 → 直接接，先加一行「进行中」
3. 最后一行写着 `进行中` → 那是有人在做的，问他还有没有别的部分
4. 没人开的作业 → 开一个 Issue，用「认领 / 分配作业」模板声明
